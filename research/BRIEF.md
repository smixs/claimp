# Ресёрч: нативный macOS-плеер в духе AIMP для подготовки DJ-миксов

Дата: 2026-09-15. Владелец: автор проекта. Цель ресёрча: НЕ писать своё, собрать плеер из готовых
open-source компонентов (GitHub) на Swift/AppKit/SwiftUI, нативно для macOS. Электрон и веб запрещены.

## Что должен уметь продукт (со слов владельца)
- Внешний вид как AIMP (скриншот `research/aimp-reference.png`): шапка с обложкой и полным названием,
  сверху крупный длинный ЦВЕТНОЙ waveform всего трека (видно начало, развитие, моменты), под ним плейлист.
- Плейлист: длительность, ГОД релиза, стандартные MP3-теги; сортировка по длительности; галочка «проиграно».
- Из плейлиста drag-and-drop реального файла в ДРУГУЮ программу (Finder, DAW, Telegram и т.п.) - там появляется файл.
- Drag-and-drop папки на плеер - открывается как плейлист.
- Простой, минималистичный интерфейс, максимальная скорость, Swift, нативно.

## Правила для каждого отчёта
1. Только первичные источники: исходный код репо (shallow clone upstream-репозитория, `clones/<repo>`;
   клоны в этот репозиторий не входят), официальные доки Apple,
   README только как навигация. Каждое утверждение - ссылка (URL) или `path:line` в клоне. Без опоры - утверждение снять.
2. «Не установлено» - допустимый ответ. Не додумывать.
3. По каждому кандидату: язык, лицензия, последний коммит (дата), открытые issues/активность, зависимости,
   что именно из него можно ВЗЯТЬ (файл/модуль), что мешает (лицензия, iOS-only, UIKit, устаревший Swift, нет macOS-таргета).
4. Проверять по коду, не по README: собирается ли под macOS (Package.swift platforms), есть ли тесты, свежесть.
5. Итог отчёта: таблица кандидатов + вердикт «берём / резерв / нет» с причиной + список открытых вопросов владельцу
   (только те, на которые нет ответа в источниках).
6. Инструменты: встроенные WebSearch/WebFetch, `git clone --depth 1`, чтение кода. Firecrawl не использовать.
   Субагентов не запускать. Ничего не писать вне этой папки проекта. Приложение не строить.
7. Формат: Markdown, русский язык, технические имена как есть. Кратко, по делу, без воды.
